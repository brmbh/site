Why Suite?

WordPress is free, open source and runs on your server. Because of agents there is no need for mega-menu plugins or complex staging environments anymore. So with this Suite you and your Agents will be able to build, manage and grow your WordPress projects with ease.

Just chat with your agent.

Coding agents and LLMs are highly capable of achieving outstanding results. WordPress delivers the infrastructure on top of it. Brmbh aims to connect both worlds. It gives you the most capable and trusted full-stack website building framework which in addition you own forever.

Add the agent skills

One command and your agent knows the full brmbh workflow: scaffold, blocks, deploy, DB sync. Works on Claude Code, Cursor, Windsurf and 30+ others.

Your agent scaffolds

Hand your agent the project name. It clones the theme, installs dependencies, builds assets, activates it in WordPress and wires its own skills into the repo.

Server and client

Vanilla PHP and a real JS build — no Blade, no black box. So one agent writes both halves: the PHP on the server and the JavaScript in the browser. Front to back, same conversation.

  • server SCF blocks · CPTs · template.php · hooks
  • client GSAP · Bootstrap JS · interactions · the build

wp-cli as a Content MCP

WordPress ships wp-cli — a full, scriptable backend. brmbh wraps it, so your agent can run the CMS like an MCP: create content, manage plugins, query the database, move environments around.

  • read query posts · options · plugin and version drift
  • write create content · activate plugins · DB pull/push
